1 Solve Simple Linear Equations with One Unknown

Definition

A linear equation with one unknown is an equation that contains only one variable raised to the power of 1. The general form is:

ax + b = c

where a, b, and c are constants and a ≠ 0.

Core Principles

  • An equation is balanced on both sides of the equals sign
  • Whatever operation you perform on one side, you must perform on the other
  • The goal is to isolate the variable (x) on one side

Solution Method

1
Identify the variable and constants
2
Collect all terms with the variable on one side
3
Collect constant terms on the other side
4
Divide by the coefficient of the variable to isolate it
5
Verify your solution by substituting back into the original equation

Example

Solve: 3x + 5 = 14

3x + 5 = 14 3x = 14 - 5 3x = 9 x = 9 ÷ 3 x = 3

Check: 3(3) + 5 = 9 + 5 = 14 ✓

Important Tips

• Always perform the same operation on both sides of the equation

• When moving a term to the other side, change its sign

• Check your answer by substituting it back into the original equation

2 Solve Simple Fractional Equations

Definition

Fractional equations (also called rational equations) contain one or more fractions with variables in the numerator and/or denominator.

Key Concepts

  • Identify the lowest common denominator (LCD)
  • Multiply all terms by the LCD to clear fractions
  • Solve the resulting linear or quadratic equation
  • Always check that solutions don't make any denominator zero

Solution Method

1
Find the LCD of all denominators
2
Multiply both sides of the equation by the LCD
3
Simplify each fraction
4
Solve the resulting equation
5
Verify the solution is not an excluded value

Example with Numerical Denominators

Solve: x/3 + 2/5 = 7/15

LCD = 15 Multiply by 15: 15(x/3) + 15(2/5) = 15(7/15) 5x + 6 = 7 5x = 1 x = 1/5 = 0.2

Example with Algebraic Denominators

Solve: 2/(x-1) + 1 = 3/(x-1)

LCD = (x-1), where x ≠ 1 Multiply by (x-1): 2 + (x-1) = 3 2 + x - 1 = 3 x + 1 = 3 x = 2 Check: x ≠ 1 ✓
3 Solve Simple Simultaneous Linear Equations with Two Unknowns

Definition

Simultaneous equations (also called systems of equations) are two or more equations with multiple unknowns that must all be satisfied by the same values.

Solution Methods

  • Substitution Method: Solve one equation for one variable, then substitute into the other
  • Elimination Method: Multiply equations so coefficients are equal, then add or subtract
  • Graphical Method: Plot both equations and find the intersection point

Substitution Method

1
Solve one equation for one variable
2
Substitute this expression into the other equation
3
Solve for the remaining variable
4
Substitute back to find the other variable

Example - Substitution Method

Solve:

x + y = 5 ... (1)

2x - y = 4 ... (2)

From equation (1): y = 5 - x Substitute into (2): 2x - (5 - x) = 4 2x - 5 + x = 4 3x = 9 x = 3 From (1): y = 5 - 3 = 2 Solution: x = 3, y = 2

Elimination Method

1
Multiply one or both equations to make coefficients equal
2
Add or subtract equations to eliminate one variable
3
Solve for the remaining variable
4
Substitute back to find the other variable

Example - Elimination Method

Solve:

2x + 3y = 7 ... (1)

3x - 3y = 3 ... (2)

Add equations (1) and (2) to eliminate y: 5x = 10 x = 2 Substitute into (1): 2(2) + 3y = 7 4 + 3y = 7 3y = 3 y = 1 Solution: x = 2, y = 1
4 Solve Quadratic Equations

Definition

A quadratic equation is a polynomial equation of degree 2. The standard form is:

ax² + bx + c = 0

where a ≠ 0.

Solution Methods

  • Factorisation: Express as (px + q)(rx + s) = 0
  • Quadratic Formula: x = (-b ± √(b² - 4ac)) / 2a
  • Completing the Square: Rewrite in the form (x + p)² = q

Method 1: Factorisation

1
Ensure the equation is in standard form: ax² + bx + c = 0
2
Factor the left side into two binomials
3
Set each factor equal to zero
4
Solve each resulting linear equation

Example - Factorisation

Solve: x² + 5x + 6 = 0

Factor: (x + 2)(x + 3) = 0 Set each factor to zero: x + 2 = 0 → x = -2 x + 3 = 0 → x = -3 Solutions: x = -2, x = -3

Method 2: Quadratic Formula

For any quadratic equation ax² + bx + c = 0, the solutions are given by:

x = (-b ± √(b² - 4ac)) / 2a The discriminant: Δ = b² - 4ac - If Δ > 0: two distinct real roots - If Δ = 0: one repeated real root - If Δ < 0: no real roots (complex roots)

Example - Quadratic Formula

Solve: 2x² - 4x - 6 = 0

a = 2, b = -4, c = -6 x = (4 ± √(16 + 48)) / 4 x = (4 ± √64) / 4 x = (4 ± 8) / 4 x = 12/4 = 3 or x = -4/4 = -1 Solutions: x = 3, x = -1

Method 3: Completing the Square

1
Rearrange to get x² and x terms on the left: x² + bx = -c
2
Add (b/2)² to both sides to complete the square
3
Write the left side as a perfect square: (x + b/2)² = ...
4
Take the square root of both sides
5
Solve for x

Example - Completing the Square

Solve: x² + 6x + 5 = 0

x² + 6x = -5 Add (6/2)² = 9 to both sides: x² + 6x + 9 = -5 + 9 (x + 3)² = 4 Take square root: x + 3 = ±2 x = -3 + 2 = -1 x = -3 - 2 = -5 Solutions: x = -1, x = -5
5 Solve Simple Linear Inequalities

Definition

A linear inequality is similar to a linear equation but uses inequality symbols instead of an equals sign. The symbols are:

< (less than) > (greater than) ≤ (less than or equal to) ≥ (greater than or equal to)

Important Rules

  • Solve inequalities like equations, with one exception
  • When multiplying or dividing by a negative number, FLIP the inequality sign
  • Solutions are typically a range of values, not just one value
  • Graph the solution on a number line

Solution Method

1
Use the same steps as solving linear equations
2
Remember to flip the inequality sign if dividing/multiplying by negative numbers
3
Express the solution as an inequality or interval notation
4
Optionally graph on a number line

Example 1 - Without Sign Flip

Solve: 2x + 3 > 7

2x + 3 > 7 2x > 4 x > 2 Solution: x > 2 or in interval notation: (2, ∞)

Example 2 - With Sign Flip

Solve: -3x + 5 ≤ 2

-3x + 5 ≤ 2 -3x ≤ -3 Divide by -3 and FLIP the inequality sign: x ≥ 1 Solution: x ≥ 1 or in interval notation: [1, ∞)

Compound Inequalities

Inequalities can be combined to show a range:

Example - Compound Inequality

Solve: -2 < x + 1 ≤ 4

Subtract 1 from all parts: -2 - 1 < x ≤ 4 - 1 -3 < x ≤ 3 Solution: -3 < x ≤ 3 or in interval notation: (-3, 3]

Interval Notation

(a, b) means a < x < b (open interval) [a, b] means a ≤ x ≤ b (closed interval) [a, b) means a ≤ x < b (half-open) (a, ∞) means x > a [a, ∞) means x ≥ a
