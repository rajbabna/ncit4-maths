01

Expressing Arithmetic Processes Algebraically

Core Idea

Algebra replaces specific numbers with letters (variables) to describe general rules. Instead of writing a specific case, we write a formula that works for all cases.

Examples
Arithmetic StatementAlgebraic Form
A number plus 5n + 5
Twice a number minus 32n − 3
The product of two numbersa × b = ab
A number squared plus anotherx² + y
Total cost of n items at price p eachTotal = np
Average of three numbers a, b, cAverage = (a + b + c) / 3
Rule of thumb: "product" → multiply, "sum" → add, "difference" → subtract, "quotient" → divide. Consecutive integers: if n is the first, the next is n+1, then n+2, etc.
02

Substituting Numbers into Formulae

Method

To evaluate a formula, replace each letter with its given value, then apply BODMAS (Brackets → Orders → Division → Multiplication → Addition → Subtraction).

Worked Example

Given v = u + at, find v when u = 5, a = 3, t = 4:

v = 5 + (3)(4) v = 5 + 12 v = 17

Given A = πr², find A when r = 7, π ≈ 3.14:

A = 3.14 × 7² A = 3.14 × 49 A = 153.86
Common mistake: Remember that 3x² means 3×(x²), NOT (3x)². Always square first, then multiply by the coefficient.
03

Formulating Equations for Given Situations

Strategy
  1. Identify the unknown and assign it a letter (e.g. x).
  2. Translate each piece of information into an algebraic expression.
  3. Set up an equation using the equals sign where two expressions are equal.
  4. Solve and check your answer in the original context.
Examples

Situation: A rectangle has length 3 more than its width w, and a perimeter of 26 cm.

Length = w + 3 Perimeter: 2(w + 3) + 2w = 26 2w + 6 + 2w = 26 4w = 20 → w = 5 cm

Situation: Three consecutive integers sum to 57.

Let integers be: n, n+1, n+2 n + (n+1) + (n+2) = 57 3n + 3 = 57 3n = 54 → n = 18 → 18, 19, 20

05

Brackets and Extraction of Common Factors

Expanding a Single Bracket

Multiply the term outside by every term inside:

a(b + c) = ab + ac 3(2x − 5) = 6x − 15 −2(x + 4) = −2x − 8 ← sign changes!
Extracting Common Factors (Factorising into one bracket)

Find the HCF of all terms, then divide each term by it:

6x + 9 → HCF = 3 → 3(2x + 3) 12a − 8 → HCF = 4 → 4(3a − 2) 5x² + 10x → HCF = 5x → 5x(x + 2)
Check: Expand your answer to verify you get back the original expression.
06

Expanding Products of Algebraic Expressions

FOIL Method (two binomials)

First · Outer · Inner · Last

(x + 3)(x + 5) = x·x + x·5 + 3·x + 3·5 = x² + 5x + 3x + 15 = x² + 8x + 15
(2x − 3)(x + 4) = 2x² + 8x − 3x − 12 = 2x² + 5x − 12
(a + b)² = a² + 2ab + b² (x + 5)² = x² + 10x + 25 (a − b)² = a² − 2ab + b² (x − 3)² = x² − 6x + 9 (a + b)(a − b) = a² − b² (x + 4)(x − 4) = x² − 16
07

Factorising Expressions of the Form ax + ay

Core Technique

Identify the common factor a, then write: ax + ay = a(x + y)

4x + 4y = 4(x + y) 6a − 9b = 3(2a − 3b) px + py = p(x + y) 3mn + 6m = 3m(n + 2) x²y − xy² = xy(x − y)
Important: The common factor can be a number, a variable, or a combination of both. Always find the highest common factor.
08

Manipulating Simple Algebraic Fractions

Simplifying

Cancel common factors in numerator and denominator:

6x / 9 = 2x / 3 (÷ 3) (x² + 2x) / x = x + 2 (÷ x) (3a + 6) / 3 = a + 2 (factorise first)
Adding & Subtracting (find LCD)
x/3 + x/4 → LCD = 12 = 4x/12 + 3x/12 = 7x/12 (x+1)/2 − x/3 → LCD = 6 = 3(x+1)/6 − 2x/6 = (3x + 3 − 2x) / 6 = (x + 3) / 6
Multiplying & Dividing
(3x/4) × (8/x) = 24x / 4x = 6 (2/x) ÷ (4/3x) = (2/x) × (3x/4) = 6x / 4x = 3/2

(a)4 marks

A father is 4 times as old as his daughter. In 6 years, he will be 3 times as old as she will be. Let the daughter's current age be x. Form an equation and solve for x. State both ages now.

✦ Model Answer
Daughter now: x | Father now: 4x
In 6 years: daughter = x + 6, father = 4x + 6
Equation: 4x + 6 = 3(x + 6)
4x + 6 = 3x + 18
x = 12 → Daughter: 12, Father: 48 ✓

The perimeter of a rectangle is 52 cm. The length is 5 cm more than twice the width. Find the dimensions of the rectangle.

✦ Model Answer
Let width = w, length = 2w + 5
Perimeter: 2(w) + 2(2w + 5) = 52
2w + 4w + 10 = 52
6w = 42 → w = 7 cm
Length = 2(7) + 5 = 19 cm ✓
Check: 2(7) + 2(19) = 14 + 38 = 52 ✓

Factorise: ax + ay − bx − by by grouping.

✦ Model Answer
Group: (ax + ay) + (−bx − by)
= a(x + y) + (−b)(x + y)
= a(x + y) − b(x + y)
= (x + y)(a − b) ✓
(c)3 marks

Show that n(n+1) − (n−1)(n+2) simplifies to a constant, and state its value.

✦ Model Answer
n(n+1) = n² + n
(n−1)(n+2) = n² + 2n − n − 2 = n² + n − 2
Difference: (n² + n) − (n² + n − 2)
= n² + n − n² − n + 2 = 2 ✓

The expression always equals 2, regardless of n.
