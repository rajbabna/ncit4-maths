1.Describe the set language and notation.

1. Use set language and set notation, and Venn diagrams, to describe sets and
represent relationships between sets as follows:
- Definition of sets, e.g.
  A = {x : x is a natural number}
  B = {(x, y): y = mx + c}
  C = {x : x ∈ U, x ∈ A or , x ∈ B }
  
- Notation:
  - Union of A and B : A ∪ B
  - Intersection of A and B : A ∩ B
  - Number of elements in set A: n(A)
  - ". . . is an element of . . ." ∈
  - ". . . is not an element of . . ." ∉
  - Complement of set A: A’
  - The empty set Ø
  - Universal set ∈
  - A is a subset of B :A ⊆ B
  - A is a proper subset of B :A ⊂ B
  - A is not a subset of B :A ⊄ B
  - A is not a proper subset of B: A ⊄B

1.Demonstrate ability to calculate probability of events.

1. Calculate the probability of a single event as either a fraction or a decimal
(not a ratio).
2. Calculate the probability of simple combined events using possibility
diagrams and tree diagrams where appropriate. (In possibility diagrams
outcomes will be represented by points on a grid and in tree diagrams
outcomes will be written at the end of branches and probabilities by the side
of the branches.)
